### Deliberate exclusions and deviations

- Unchanged bootstrap, shared settings, existing instrumented content/navigation/test endpoints, and server rendering components needed no additional wiring.
- Data models, cache sizing, metadata/key predicates, role-set operations, in-memory filters/count composition, and per-item parsing/scoring remain uninstrumented. Their frequency or low diagnostic value is the exclusion reason, not static/private binding.
- Pure forwarding wrappers and framework assembly-resolution callbacks remain unchanged.
- WASM/client source is untouched.
- Static activity loggers cache a real factory-created logger, not the temporary null fallback. This avoids permanently disabling logs when a standalone test calls startup helpers before bootstrap.
- Configuration-bound role-provider options use a class-scoped cached logger because the binder constructs them without constructor injection.
- Existing explicit logger parameters in startup helpers remain for compatibility with their existing log messages.
- Folder-record tracing starts inside the awaited local function and uses the public method name, preserving the original synchronous wrapper and task lifetime.
- Shared configuration remains unchanged. The normal source is already covered by Diginsight and OpenTelemetry settings. Former HotPath settings remain for compatibility but no longer gate server call sites.
- More lookup spans are intentionally enabled by using one source. This run didn't benchmark production telemetry cost.

### Conclusion

Implementation, compilation, automated behavior checks, cache-key formatting, and parent correlation are verified. Visible-browser validation is still required before this change has full sign-off.
