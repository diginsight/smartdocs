## ✅ Verification and outcome

The supplied delegated user scope succeeds against the provider's current-user role API, whereas administrative lookup rejects the same token. The provider now checks the current-user response's application and member, reads grouped repository values, and filters expired roles and values. Unsupported property types and explicit operators don't grant access.

The unchanged repository metadata maps scoped roles to permissions. The passing run confirms that authentication isn't a `Read` grant and a scoped administrator role isn't a global bypass. The legacy administrative mode remains available for explicitly configured application integrations.

## ⚠️ Notes

This is **local acceptance**, not hosted acceptance. No deployment, cloud setting change, secret write, or consent grant was performed. Hosted sign-in still requires a working confidential-client credential under `AzureAd` and removal of stale application-mode or administrative-endpoint overrides. Multiple workers and long-lived token-cache recovery weren't tested.

The temporary host was stopped after validation; the browser remains available. The earlier failed run is preserved as historical evidence.
